## 🔍 Project Overview
This repository contains my **IBM Data Analyst Capstone Project**, analyzing **~90,000 developer responses** from the Stack Overflow Developer Survey to identify **current and future technology adoption trends**.

The project demonstrates **end-to-end analytics**: data acquisition, cleaning, EDA, statistical modeling, machine learning, and dashboard-driven storytelling.

---

## Project Scope

The project covers the following analytical components:

1. Data acquisition from APIs, CSV files, and web scraping.
2. Data cleaning, transformation, and feature engineering.
3. Exploratory data analysis (EDA) across multiple technology categories.
4. Predictive modeling using regression, classification, and clustering.
5. Dashboard development using IBM Cognos Analytics.
6. Insight synthesis and reporting for decision‑making.

---

## 🎯 Objectives

- Identify **current technology adoption trends**
- Forecast **future technology preferences**
- Analyze **developer demographics and workforce patterns**
- Deliver **decision-ready insights** through dashboards and visual analytics

---

## 🧪 Methodology

**Data Collection**
- APIs and CSV datasets
- Web scraping using `BeautifulSoup` and `Requests`

**Data Preparation**
- Data cleaning, normalization, and feature engineering
- Handling missing values and outliers
- Correlation and distribution analysis

**Exploratory Data Analysis (EDA)**
- Trend analysis across languages, databases, platforms
- Demographic segmentation
- Time-based and comparative analysis

**Modeling & Analytics**
- **Logistic Regression**
  - Accuracy: **83%**
  - Precision: **0.81**
  - Recall: **0.79**
  - F1-score: **0.80**
- **Linear Regression**
  - R²: **0.76**
  - RMSE reduced by **18%** after feature optimization
- **K-Means Clustering**
  - k = 4
  - Silhouette Score: **0.62**

## 📈 Key Findings

### Programming Languages
- **HTML/CSS** remains the most widely used
- **Python** is the fastest-growing language
- Increasing adoption of **JavaScript**

### Databases
- **MySQL** is the most commonly used
- Strong projected growth for **PostgreSQL**
- Declining interest in **Firebase** and **DynamoDB**

### Platforms & Frameworks
- High adoption of **Docker, AWS, Linux**
- Growing interest in **React, Angular, Spring**

### Demographics
- ~**90% male** developer population
- Majority located in **developed countries**
- Undergraduate education dominates → postgraduate degrees not a prerequisite
